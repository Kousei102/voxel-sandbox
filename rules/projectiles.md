## 飛んでいるもの（火球・矢・エンダーアイ・ブレス・卵・雪玉）

判断は `projectiles.ts` に全部あります。**新しい GLSL・WebAudio・DOM は 1 行も足していません**
（見張りは `test/projectiles.test.ts`）。`drops.ts` ↔ `droprender.ts` とまったく同じ対の形です。

| ファイル | 中身 | 確かめ方 |
| --- | --- | --- |
| `projectiles.ts` | **判断は全部ここ。** 表・物理の数値・寿命・上限・当たり判定・見た目の向き | `npm test` |
| `projectilerender.ts` | three だけ（`Mesh` / マテリアル / 毎フレームの同期）。**判断を書かない** | ブラウザ |

- **種類を足すのは `PROJECTILE_KINDS` に 1 行**で、飛び方の実装は増やさないこと。
  6 種類（火球・矢・エンダーアイ・ブレス・**卵**・**雪玉**）の違いは全部この表の値です。
- **雪玉は卵の値をそのまま写したものです**（速さ 20 / 重力 x1 / 抵抗 0 / 寿命 30 /
  半径 0.125 / `vanish` / 光らない / 向かない）。本家でも雪玉と卵は同じ速さなので、
  **片方だけ触ると、同じ手で投げたものの弾道が食い違います** ——
  `test/projectiles.test.ts` が 8 つの値を突き合わせています。
- **プレイヤーが投げるものは、表とは別に `items.ts` の `THROWN` を通ります。**
  「どのアイテムを投げると何が飛ぶか」は `items.ts` の表 1 本（`thrownProjectile()`）で、
  **どう飛ぶか**はここの表 1 行 —— この 2 つを混ぜないこと。`use.ts` にも `main.ts` にも
  **`held === EGG` と書かないこと**（`isBucket` / `isBow` とまったく同じ作法で、
  書くと投げるものが増えるたびに `decideUse()` に分岐が 1 本ずつ生えます）。
  **`items.ts` と `use.ts` が `projectiles.ts` から取ってよいのは
  `import type { ProjectileKind }` だけです** —— 値で入れると輪になりますし、
  `test/use.test.ts` が `use.ts` に `Projectiles` が出てこないことを見張っています。
- **卵は当たっても何も起きません**（`Shot.damage` を渡さない = 既定の 0。
  `mobs.ts` の `hitByProjectile()` が `shot.damage <= 0` で戻ります）。
  **表にダメージを書かないこと**は今までどおりで、**渡さないことがそのまま
  「当たっても減らない」になります。**
- **本家の「1/8 でヒヨコが孵る」は入っていません**（子モブの仕組みが 1 つも無いため）。
  入れるなら `mobs.ts` の話で、`projectiles.ts` の表は 1 行も動きません。
- **当たったときに何が起きるかは表に書きません。** ダメージの数値・爆発・要塞の方角は
  手応えを決めるものなので（`LOOP.md` の停止条件 4）、**当たったマスを `onHitBlock` で、
  当たった相手を `onHitTarget` で外へ渡すだけ**にしてあります。
- **誰に当たったか（`ProjectileTarget`）も同じ形です。** ここが持つのは「重なったか」という
  形の話だけで、**何がどれだけ減るかは撃った側が弾に載せます**（`Shot.damage`）。
  - **相手は呼ぶ側が毎フレーム集めて渡します**（`Mobs.projectileTargets()`）。だから
    `projectiles.ts` は `mobs.ts` も `player.ts` も知らないままでいられます
  - **撃った本人（`Projectile.owner`）には当たりません。** 口元・手元から出るので、
    見ないと必ず自分に当たります（外すとブレイズが自分の火球で焼け死にます。実測）。
    印は **`PLAYER_OWNER`(0) がプレイヤー、モブは自分の `id`（1 から）**
  - **相手も `MAX_STEP`(0.2m) ごとに見ること。** 壁と同じで、刻まないと速い矢が
    立っている相手をまたぎます（`test/projectiles.test.ts` が押さえています）
  - **相手を先に、ブロックをあとに見ること。** 逆にすると、壁を背にした相手に当てたとき
    同じ刻みで壁が勝って、当たったのに何も起きません
  - **当たった相手には、刺さるもの（矢）も残らず消えます。** 体に刺さった矢を持ち歩かせる
    仕組みが無いので、壁と同じ扱いにすると宙に浮いた矢が残ります
  - **素通りするもの（`onBlock: "pass"`。エンダーアイ）は相手も見ません** ——
    案内役なので、通り道に立った人を撃つ道理がありません
- **モブと同じで保存しません**（落とし物は逆に保存します。`rules/drops.md`）。
  読み込んだ瞬間に矢が刺さり直したり火球が飛んでくるより、消えているほうが安全側です。
- **`world.setVoxel` を呼びません**（モブ・落とし物と同じ制約。`edits` は
  プレイヤーの操作でなければならず、セーブがそれに乗っています）。
- **未生成の列では動かしません**（`world.hasColumn(columnOf(x), columnOf(z))`）。
  無いと `getVoxel` が AIR を返して壁を抜けていきます。
- 奈落（`y < VOID_Y`）は寿命任せにせず、その場で消します。有限に保つのは
  **寿命（種類ごと）と上限（`MAX_PROJECTILES` 64）の 2 本**で、**距離では消しません**
  （撃った先が見えない所で消えると、当たったのか出ていないのか分かりません）。
  上限に当たったら**古いほうから**捨てます。
- **重力・終端速度は自前で持ちます**（`player.ts` / `mobs.ts` / `drops.ts` と同じ形。
  速度の作り方が違うので共有していません）。**片方だけ変えないこと。**
- **`position` は体の中心です**（落とし物は足元の中心）。回して向きを変えるので、
  中心のほうが素直です。`physics.ts` に渡すときだけ `y - half` に直します。
- **当たり判定は `MAX_STEP`(0.2m) ごとに刻むこと。** 矢は 40m/s なので、1/20 秒の重いフレームでは
  1 回に 2m 進み、**刻まないと厚さ 1 マスの壁を飛び越えます**（テストが押さえています）。
- **ぶつかったら手前で止めること。** めり込んだ位置に置くと、刺さった矢が壁に埋まって
  見えなくなります。テストは「壁より手前か」ではなく**箱の前面がマスの面より手前か**を
  見ています（前者だと半分めり込んでいても通ります。実際に通りました）。
- 壁に当たったときの振る舞いは `onBlock` の 3 つ: `vanish`（火球・ブレス）/
  `stick`（矢。止まって寿命まで残る）/ `pass`（エンダーアイ。**ブロックを見ない** ——
  要塞は地面の下なので、止まると案内になりません）。
- **当たった先が消えたときは `remove(projectile)` で弾も消すこと。** `onHitBlock` の
  中から呼んでよく（走査が後ろから回るので、いま見ている番号を抜いても前側は動かない）、
  **`onExpire` は呼ばれません**（寿命でも上限でもなく、当たって役目を終えたぶんなので、
  当たって消える火球と同じ扱い）。**エンドクリスタルを砕いた矢がこれです** ——
  消さないと、砕けた相手だけが消えて矢が空中に浮いたまま残ります。
- **見た目の向きは `projectiles.ts` が `yaw` / `pitch` に焼きます。** 描画側で速度から
  作り直さないこと —— 刺さって止まった瞬間に速度が 0 になるので、矢の向きがその場で戻ります。
  `test/projectiles.test.ts` が `projectilerender.ts` に `velocity` が出てこないことを見ています。
- **自分で光るもの（`glows`）は周りの明るさを見ません。** 暗いネザーの通路で火球が見えないと
  避けようがないためで、決めているのは表、描画はその分岐を貼るだけです。
- 形は `mobmesh.ts` の `buildBoxMesh()`、色は `mobRgb()`、光は `useTerrainLighting()` +
  `voxelLight` 属性。**ブロック・モブ・落とし物とまったく同じ道を通すこと。**
- **`projectiles.update()` は `world.update()` の外**で回します（モブ・落とし物と同じ理由）。
- `main.ts` の **`N` キー**が 6 種類を順ぐりに 1 つ撃ちます（`M` のモブ出しと同じ、
  切り分けのためのデバッグ用）。**卵は右クリックで投げられるので本物の手段がありますが、
  `N` は表の全部を出せる唯一の道**です（火球・ブレスを出す手段はほかにありません）。
  **飛んでいるものを絵で確かめるときは、空を向いてから撃つこと** —— 地面へ向けると
  草の上の 0.25m の四角になって、撮った PNG から何も読めません（雪玉の周で撮り直した。
  `docs/browser-shots/README.md`）。
- **ブレスは火球とまったく同じ飛び方です**（`gravityScale` 0 / `drag` 0）。速さだけが
  2.5 倍（30m/s）で、**プレイヤーの 10 マス上から撃ち下ろす**ためのものです。
  山なりに戻すと、狙った所より手前へ落ちて当たりません。**「ブレスは雲のように漂う」
  という本家の像に寄せ直すなら、撃つ側（`DRAGON.phases` の高さと間隔）ごと考え直すこと。**
