## 弓（引いて放つ）

判断は `bow.ts` に全部あります。**掘る（`mining.ts` の `Mining`）・食べる（`vitals.ts` の
`Eating`）とまったく同じ形**で、押しているあいだだけ進み、離した瞬間に結果が出ます。
**新しい GLSL・WebAudio・DOM は 1 行も足していません**（見張りは `test/bow.test.ts`）。

| ファイル | 中身 | 確かめ方 |
| --- | --- | --- |
| `bow.ts` | **判断は全部ここ。** 引きの長さ・放てる下限・ダメージ・中断する条件・撃ち出す高さ | `npm test` |
| `items.ts` | どれが弓か（`isBow()`。`isBucket()` / `isFireStarter()` と同じ表 1 本） | `npm test` |
| `projectiles.ts` | 飛び方（矢の速さ・重力・寿命・刺さり方） | `npm test` |
| `main.ts` | 繋ぎだけ（引き始める・毎フレーム進める・離したら矢を減らして飛ばす） | ブラウザ |

- **当たる側には 1 行も要りません。** 矢が誰かに当たれば `projectiles.onHitTarget` →
  `mobs.hitByProjectile()`、ブロックに当たれば `onHitBlock` → `shatterCrystal()` に
  もう繋がっています。**弓の周で足したのは「撃つ側」だけ**です。
- **ダメージは撃つ側が載せます**（`Shot.damage`。`rules/projectiles.md` の「表にダメージを
  書かない」の、撃つ側がこれ）。引き具合から数を作るのは **`arrowDamage()` 1 か所**で、
  `main.ts` や `projectiles.ts` に `power * 9` を書き始めると調整のときに探せなくなります。
- **中断する条件は `Drawing` に集めること**（画面が変わった・手を持ち替えた・矢が尽きた）。
  `main.ts` に散らすと、器や画面を足すたびに 1 つずつ抜けます（`Eating` で通った道）。
- **`release()` は必ず引きを終わらせること**（放てなかったときも）。**2 回呼んでも 2 本は
  出ません** —— 離したのと画面が変わったのが同じフレームに来ることがあります。
- **浅い引きでは放ちません**（`MIN_POWER`）。本家は浅いほど矢が遅く飛びますが、
  **こちらは矢の速さが `PROJECTILE_KINDS` の固定値**なので、真似ると
  「浅く連打するほど強い」になります。速さを `Shot` に載せる形にするなら外せます。
- **満引きに達した合図は音だけです**（`sfx.ts` の `bow` を `FULL_DRAW_PITCH` 倍で）。
  **この環境では引く動きを描けない**ので、消さないでください（咀嚼音と同じ役）。
- **矢を減らすのは `main.ts`**（`bow.ts` は持ち物を知りません）。クリエイティブで
  減らさないのは、ブロックを置くのとまったく同じ扱いです。
