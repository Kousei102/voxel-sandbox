## エンドクリスタル（`crystals.ts`）

**エンドの黒曜石の柱の上に 1 個ずつ載ります**（居場所は `endgen.ts` の `CRYSTAL_SPOTS`）。
判断は `crystals.ts` に全部あり、three も DOM も乱数も出てきません
（見張りは `test/crystals.test.ts`）。

| ファイル | 中身 | 確かめ方 |
| --- | --- | --- |
| `blocks.ts` | ブロック `END_CRYSTAL`(54) の形と性質 | `npm test` |
| `endgen.ts` | **居場所**（`CRYSTAL_SPOTS` / `crystalTopAt`）と生成 | `npm test` |
| `crystals.ts` | **判断は全部ここ。** 生き死にを読む・砕く | `npm test` |
| `main.ts` | 繋ぎだけ（`projectiles.onHitBlock` を `shatterCrystal()` へ） | ブラウザ |

- **モブでも独立した器でもなく、ブロックです。** 「柱の上に載る・壊せる」しか
  要らないので、**新しい `*render.ts` を 1 つも増やさずに済みます。**
  決め手は 2 つとも「壊せる」に効きます:
  - **壊した記録が `edits` に乗る。** モブは保存しないので、モブ側の表に載せると
    **壊したクリスタルが読み込み直しで生き返り**、ドラゴンの回復がそのぶん戻ります
  - **当たり判定を書かなくてよい。** 掘るのも飛び道具（`projectiles.onHitBlock`）も
    もともとブロックに当たります
- **`solid: true` でないと飛び道具が素通りします**（`collisionBoxes()` が `solid` で
  ないブロックに空の箱を返すため）。**矢で壊せることがクリア導線**なので、ここは崩せません。
- **`variantOf` を持たないので、アイテム ID 54 が自動でできます**（1..63 の決まり）。
  **`DROPS` に「何も落ちない」を書くこと** —— 拾えると、柱の上へ運び直して
  ドラゴンの回復を復活させられます。
- **居場所は `endgen.ts` の `CRYSTAL_SPOTS` 1 か所**（`PILLARS` から `top + 1` で引く）。
  **写して 2 か所に持たないこと** —— 柱の並びを動かしたときに**柱の無い所に
  クリスタルが浮きます**（空中なので、下から見上げるまで気付けません）。
  `test/crystals.test.ts` が `crystals.ts` に `PILLAR_RING` / `Math.cos(` が
  出てこないことを見張っています。
- **虚空の列に載せないこと。** 保険は `blockAt()` が `VOID_COLUMN` を**先に**見る
  1 行だけで、`crystalTopAt()` は種を受け取らない＝島の形を知りません
  （`pillarTopAt()` とまったく同じ作り）。
- **生き死には `hasColumn` を見ること**（`CrystalReader`）。未読み込みの列では
  `getVoxel` が AIR を返すので、見ないと**エンドに降りた直後に 10 個とも
  「砕けた」と読みます**（かまどの `syncLit()` / ベッドの `moveToSpawn()` と同じ罠）。
  状態は 3 つ（`alive` / `gone` / `unknown`）で、**`unknown` は生きているに数えません** ——
  数えると、着いた直後に**砕いたはずのクリスタルからドラゴンが回復し続けます。**
- **`shatterCrystal()` は居場所の表と突き合わせません。** 見るのはそのマスに実際に
  何があるかだけで、クリエイティブで柱の外に置いたものも同じように砕けます
  （置けるものが場所によって壊せたり壊せなかったりするほうが不可解です）。
  返すのは**砕けたブロックの ID**（何も起きなければ `AIR`）—— 呼ぶ側が
  「当てた弾を消すかどうか」を決められるようにするためです。
- **砕いた弾はその場から消すこと**（`main.ts` が `projectiles.remove(shot)`）。
  矢は本来ブロックに刺さって止まるので、消さないと**砕けた相手だけが消えて、
  矢が空中に浮いたまま残ります**（`test/ui.test.ts` が呼び直しを見張っています）。
- **`update(dt)` を持ちません**（`chests.ts` と同じ。毎フレーム進むものがありません）。
- **爆発しません**（本家は当たると爆発してプレイヤーにもダメージが入ります）。
  火そのものが無いのと同じ理由で、爆発の仕組みから作ることになります。
